# LI-COR Intermediate

> LI-COR Intermediate, Inc. is the Battery Ventures-backed holding entity for LI-COR, a Lincoln, Nebraska maker of environmental and life-science instrumentation. LI-COR Environmental builds greenhouse-gas analyzers, eddy-covariance flux systems and the HOBO data logger line; LICORbio builds Western blot imaging systems and infrared fluorescent reagents. Connected devices report into LI-COR Cloud (formerly HOBOlink), which publishes a read-only HOBOLINK External API for pulling logger and sensor observations.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. No provider-published /llms.txt exists (404 on www.licor.com and www.licorbio.com).

## APIs

- [HOBOLINK External API](https://api.licor.cloud/v1/docs): Read-only REST API returning time-series observations from HOBO data loggers and their sensors. Base URL https://api.licor.cloud. JWT bearer auth. 60 requests per minute.

## Specs

- [OpenAPI 3.0.0 — HOBOLINK External API](openapi/li-cor-intermediate-hobolink-openapi.json): Two GET operations, /v1/data and /v1/newa/{device-serial-number}.
- [OpenAPI Overlay](overlays/li-cor-intermediate-hobolink-overlay.yaml): API Evangelist enhancements — operationIds, tags, summaries the upstream spec omits.

## Operations

- `GET /v1/data` — observations for a comma-separated list of logger serial numbers over a UTC range. Required: `loggers`, `start_date_time`, `end_date_time`. Returns `{message, max_results, data[]}`.
- `GET /v1/newa/{device-serial-number}` — sensor-grouped observations for one device over a UTC range. Required path `device-serial-number`, query `start_date_time`, `end_date_time`. Returns `{more_data, sensors[]}` with nested `observations[]`.

## Conventions

- Auth: `Authorization: Bearer <JWT>` on every operation. See [authentication](authentication/li-cor-intermediate-authentication.yml).
- Time: all date-times are UTC in `yyyy-MM-dd HH:mm:ss` format; both start and end are required.
- Pagination: none. Truncation is signaled by the `max_results` (/v1/data) and `more_data` (/v1/newa) booleans — narrow the date range rather than paging.
- Errors: class-prefixed codes, not RFC 9457. See [error codes](errors/li-cor-intermediate-error-codes.yml).
- Rate limits: 60 requests / 60 seconds, signaled via `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset`. Exceeding returns 429 `SYS-002`. See [rate limits](rate-limits/li-cor-intermediate-rate-limits.yml).
- Full conventions: [conventions](conventions/li-cor-intermediate-conventions.yml)
